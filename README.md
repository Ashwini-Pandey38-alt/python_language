# 🐍 Python Learning Journey

A collection of Python fundamentals and practice exercises documenting my progress as I learn to code. This repository includes small programs for exploring core concepts and solving beginner-level problems.

## 📚 Topics Covered

- 🔢 Variables, user input, and type conversion
- ➕ Arithmetic and simple calculations
- 🔀 Conditional statements and loops
- 🧩 Functions
- 🔤 String operations and palindrome checks
- 📋 Lists, tuples, sets, and dictionaries
- 🧠 Practice problems, including prime numbers, factorials, and number guessing
- ⭐ Pattern printing
- 🏗️ An introduction to classes and objects

## 📁 Repository Contents

- `basic.py` — Examples using variables, input, arithmetic, and loops
- `question.py` — Python practice problems covering several fundamentals
- `python_language/` — Notes about my learning progress
- `let.js` — Empty file reserved for JavaScript practice
